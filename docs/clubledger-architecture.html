📐 Architecture Overview v2.4.0

ClubLedger — System Architecture

Offline-first Android treasury platform with attendance-proportional cost allocation, multi-team governance, cloud-native multi-device sync, and a 5-layer distributed defense stack.

🎯 Business Context & Objectives
💰

Fair-Share Treasury

Proportional cost allocation based on verified attendance — members pay only for sessions attended.

📊

Full Audit Trail

Immutable append-only ledger with running balances, admin-verified deposits, and dispute resolution logs.

👥

Multi-Team Governance

Superset role hierarchy (Global Admin → Team Admin → Captain → Member) with granular team isolation.

☁️

Cloud-Native Sync

Offline-first Room SQLite with optional real-time Firestore multi-device synchronization via idempotent keys.

✨ Functional & Non-Functional Features

Functional Requirements

📋

Attendance Self Check-In & Roster Quick-Mark

Members submit attendance; captains/coaches 1-tap mark full roster. Admin approval workflow.

💵

Proportional Cost Allocation Engine

Fair-share formula: memberShare = (sessions / totalSessions) × totalCost. Zero-attendance → $0.

🧾

Receipt Proof & Invoice Generation

Admin declares incurred costs with PDF/image receipt proofs. Members inspect line-by-line calculations.

💳

Multi-Channel Payment Logging

Zelle, Venmo, Bank Transfer, Cash — all with admin verification before ledger credit.

⚖️

Dispute Resolution Workflow

Members raise formal attendance/invoice disputes. Adjudication generates compensating ledger entries.

📊

CSV Export for AGM Auditing

1-click export of ledger, attendance, and payment data for Annual General Meeting bookkeeping.

Non-Functional Requirements

📱

Offline-First Architecture

Room SQLite serves all UI reads instantly. Cloud sync is optional and additive — never blocking.

🛡️

5-Layer Defense-in-Depth

Edge DDoS, Play Integrity attestation, rate limiting, Firestore ACL, budget hard caps.

🔒

Immutable Append-Only Ledger

No user can delete historical financial transactions. All records remain AGM-verifiable.

🏗️

Room Migration Safety (v1→v2)

Safe column alterations with backward compatibility and zero data loss on app upgrades.

✅

45+ JUnit/Robolectric Test Suite

Covers allocation engine, ledger balance, CSV generator, permission engine, and security defense.

🚀

GitHub Actions CI/CD

Automated test → build → release bundle pipeline on every push to main. Keystore-based signing.
