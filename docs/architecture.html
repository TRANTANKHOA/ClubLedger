🏛️ System Architecture & Data Flow
Module 2

ClubLedger is built upon modern Android architecture utilizing Jetpack Compose for declarative UI, Kotlin Coroutines & Flow for real-time reactivity, Room Database with migration safety, and a decoupled Repository & ViewModel MVVM pattern.

Entity Relationship & Database Schema

Entity Primary Key Foreign Keys Key Responsibility
User id (Long) — Player profile, email, role (GLOBAL_ADMIN, TEAM_ADMIN, CAPTAIN, MEMBER)
Team id (Long) captainUserId, treasurerUserId Sport team, invite code, default pitch fee, join link active flag
TeamBudget id (Long) teamId, declaredByUserId Incurred cost declarations with category and attached receipt proofs
Invoice id (Long) budgetId, teamId Published billing cycle with total approved sessions & per-session cost
InvoiceAllocation id (Long) invoiceId, userId Individual member calculated share and payment settlement status
AttendanceRecord id (Long) fixtureId, userId, verifiedBy Verified check-in status (APPROVED, REJECTED, PENDING) with check-in time
Transaction id (Long) userId, teamId, referenceId Immutable ledger log with running balance after debit or credit
Dispute id (Long) userId, resolvedByUserId Audit dispute ticket on attendance overcharge or invoice variance
