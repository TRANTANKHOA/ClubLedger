🏛️ System Architecture & Data Flow
Module 2

ClubLedger is built upon modern Android architecture utilizing Jetpack Compose for declarative UI, Kotlin Coroutines & Flow for real-time reactivity, Room Database with migration safety, and a decoupled Repository & ViewModel MVVM pattern.

📐 Open Interactive SVG Architecture & Data Flow Diagram ↗

The interactive deep-dive is the canonical reference: it renders the end-to-end data flow, the layered system architecture, the complete 12-entity Room schema, the CI/CD pipeline, and the technology stack as SVG diagrams. The summary below is the quick orientation.

🎨

Presentation

Jetpack Compose Material 3 — member dashboards, admin approvals, invoices & receipts, attendance & payments.

🔄

ViewModel & State

MVVM via ClubViewModel: StateFlow emissions, reactive aggregation (balance, attendance ratio), permission engine.

⚙️

Domain & Repository

ClubRepository coordinates ACID transactions, the cost-allocation engine, and immutable ledger entries.

🗄️

Local Persistence

Room SQLite v2 — 12 entities with migration-safe upgrades, serving all UI reads offline-first.

☁️

Cloud Sync (Optional)

FirestoreSyncManager pushes with idempotent compound keys under Firestore rules ACLs — never blocking local flows.

🛡️

Cross-Cutting Defense

SecurityDefenseHelper applies rate limiting, input sanitization, and payload caps across every layer.

📐

The full 12-entity table with primary keys, foreign keys, and responsibilities lives in the interactive architecture diagram alongside the SVG data-flow and deployment views.
