🚀 Production Engineering & CI/CD Pipeline
Module 5

ClubLedger features an enterprise-grade delivery pipeline automated via GitHub Actions, comprehensive JVM unit testing, APK artifact bundling, and release packaging.

⚙️

Continuous Integration (CI)

Every PR and push to main runs standard Gradle compilation, JVM unit tests, and generates a debug APK test artifact.

📦

Automated Release Bundling (CD)

Automatic generation of optimized Android App Bundles (.aab) signed with release keystore credentials upon merge to main.

GitHub Actions CI/CD Pipeline Configuration

name: ClubLedger CI/CD Pipeline on: push: branches: [ main, release/* ] pull_request: branches: [ main ] jobs: build_and_test: name: Build & Test Android App runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - uses: actions/setup-java@v4 with: distribution: 'temurin' java-version: '17' cache: 'gradle' - name: Run Unit & JVM Tests run: ./gradlew testDebugUnitTest --continue - name: Build Debug APK run: ./gradlew assembleDebug - name: Upload Debug APK Artifact uses: actions/upload-artifact@v4 with: name: app-debug-apk path: app/build/outputs/apk/debug/*.apk

Production Build Verified

The build toolchain compiles with Gradle (Kotlin DSL), JDK 17, AndroidX Compose Material 3, and Room SQLite KSP with zero deprecation warnings.
