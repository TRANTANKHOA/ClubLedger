🔄 Portability, KMP Readiness & Exports
Module 3

ClubLedger’s domain entities, mathematical allocation formulas, and data repositories are engineered for frictionless portability across Android, Kotlin Multiplatform (KMP), Desktop (JVM), and Cloud Sync engines.

📦

Clean Architecture Decoupling

Pure Kotlin data classes and zero Android framework dependencies in the calculation engine enable drop-in reuse across iOS (Kotlin/Native), Web (KMP/Wasm), and backend Kotlin microservices.

📊

Universal CSV & Financial Exports

1-Click comprehensive CSV export of the entire ledger, attendance matrices, and invoice breakdowns suitable for standard spreadsheet software (Excel, Google Sheets, QuickBooks).

☁️

Offline-First with Cloud Sync Readiness

Room local-first persistence guarantees 100% functionality on pitch-side offline mode, ready for synchronization with Firebase Firestore or PostgreSQL.

🔗

Deep-Link & Share API

Uniform URI schema (clubledger://join?code=...) enables instant team sharing over WhatsApp, SMS, Slack, and email across any mobile device.

// Portable Calculation Function (KMP Common Code) fun calculateMemberAllocations( totalIncurredCost: Double, memberAttendanceMap: Map<Long, Int> // userId -> verifiedCount ): Map<Long, Double> { val totalSquadSessions = memberAttendanceMap.values.sum() if (totalSquadSessions == 0) return memberAttendanceMap.mapValues { 0.0 } return memberAttendanceMap.mapValues { (_, attended) -> val exactShare = (attended.toDouble() / totalSquadSessions) * totalIncurredCost kotlin.math.round(exactShare * 100.0) / 100.0 // Cent-perfect rounding } }
